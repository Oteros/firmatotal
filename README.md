# Firma Total

Private browser-based PDF signing:

- visible handwritten, typed or uploaded signatures;
- local PAdES signing with an imported PKCS#12 certificate;
- optional AutoFirma desktop integration for Spain;
- 15 interface languages;
- generated editorial SEO pages and sitemap.

Documents and certificate passwords are not sent to Firma Total servers.

## Development

```sh
npm install
npm run dev
```

## Validation

```sh
npm test
npm run build
```
