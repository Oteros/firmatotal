Digitally sign a PDF with a PAdES certificate

Create a cryptographic PDF signature using your .p12 or .pfx certificate, with local browser processing.

Sign a PDF ↓
  1. 01

    Prepare the file and its password

    The browser method needs a .p12 or .pfx containing an RSA private key and its matching certificate, plus the password. A public .cer file cannot replace it. The tool checks that the file opens, the key matches the certificate and the validity dates allow signing before it creates the signature.

  2. 02

    A visible mark is optional

    To digitally sign a PDF with no previous signatures, select the certificate and sign without drawing anything. If you also want a visible mark, place it first. When the PDF already has digital signatures, the .p12 method stops; use AutoFirma without adding a new visible mark, then check all signatures in the result.

  3. 03

    Verify the signature, not just the download

    Open the signature panel in a compatible reader and check the signer, document integrity and certificate trust. This tool does not validate the trust chain or revocation status. The .p12 method adds neither an authority timestamp nor long-term validation data. Check the recipient's requirements before sending the document.

PAdES

An image is not a certificate

A drawn or typed signature is an image: it does not verify the signer's identity by itself. A certificate signature links the document to a key and lets a reader check for later changes. Acceptance depends on the recipient, certificate and applicable rules; PAdES format does not guarantee a qualified signature.
