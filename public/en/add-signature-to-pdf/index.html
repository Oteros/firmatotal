Add a handwritten signature to a PDF

Draw, type or import a signature, place it precisely on any PDF page and download the finished document.

Sign a PDF ↓
  1. 01

    One page, one position

    In a three-page PDF, select page 3 and press “Add to this page” once. The signature appears only there. Drag it inside the paper to the reserved space, leaving room for the name and date added below it during export. The preview shows the signature image.

  2. 02

    The same signature on three pages

    “Add to all pages” creates a position on every page, even when you are only viewing one. Move each mark separately or remove it with the cross. Pressing the button again adds more positions: use the arrows to check for duplicates and to inspect pages with different sizes or margins.

  3. 03

    What the name and date mean

    The name is the text you enter; it is not checked against an identity. The date uses the device clock and selected language, and is not a certified timestamp. Characters from other writing systems are preserved; when browser rendering is needed, the line is stored as an image rather than selectable text.

PAdES

An image is not a certificate

A drawn or typed signature is an image: it does not verify the signer's identity by itself. A certificate signature links the document to a key and lets a reader check for later changes. Acceptance depends on the recipient, certificate and applicable rules; PAdES format does not guarantee a qualified signature.
