Signer un PDF en ligne sans le téléverser

Ajoutez une signature visible à un PDF dans votre navigateur, sans compte ni envoi vers un serveur.

Signer un PDF ↓
  1. 01

    Exemple : une autorisation de trois pages

    Ouvrez le PDF et utilisez les flèches pour atteindre la page 3, où se trouve le cadre de signature. Créez votre signature, validez-la et ajoutez-la à cette page. Faites-la glisser dans le cadre sans masquer le texte. Les deux premières pages n’ont pas besoin d’une marque supplémentaire si le destinataire demande seulement une signature à la fin.

  2. 02

    Dessiner, saisir un nom ou choisir une image

    Dessinez à la souris ou au doigt, saisissez votre nom ou choisissez une image PNG, JPEG ou WebP. Un PNG transparent évite de masquer le document. La taille des noms saisis s’adapte à l’espace, y compris pour les noms longs. Vérifiez le tracé avant de le placer : toutes les positions ajoutées utilisent la même image.

  3. 03

    Vérifiez la copie téléchargée

    Téléchargez la version avec signature visible et ouvrez-la dans un lecteur PDF. Vérifiez les trois pages, le nom et la position. Sans signature placée, vous obtenez une copie de l’original. L’image n’ajoute ni certificat ni preuve d’identité ; assurez-vous que le destinataire accepte ce type de signature.

PAdES

Une image n’est pas un certificat

Une signature dessinée ou saisie est une image : elle ne vérifie pas à elle seule l’identité du signataire. Une signature avec certificat lie le document à une clé et permet de détecter les modifications ultérieures. Son acceptation dépend du destinataire, du certificat et des règles applicables ; le format PAdES ne garantit pas une signature qualifiée.
